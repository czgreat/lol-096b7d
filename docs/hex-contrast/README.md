# 海克斯反差榜（数据页 + 分享图）

用内置的 Hexdata 国服 16.19 数据，展示"看着普通、其实几乎谁拿都赚"的海克斯（科学狂人、逃跑计划、全能龙魂）、"看英雄拿"的虚幻武器，以及几组单英雄神组合。

| 文件 | 说明 |
|---|---|
| `海克斯反差榜.html` | 成品网页，浏览器直接打开。字体从 Google Fonts 加载，离线时退回系统字体 |
| `template.html` | 网页模板：样式和文字；`@sci`、`@S1pos` 这类占位符由脚本填数据 |
| `make_html.py` | 读 `bundled-data/hexdata.json`，填模板，生成 `海克斯反差榜.html` |
| `to_images.py` | 把网页按段落转成分享图片，输出到 `images/` |
| `images/` | 已生成的 5 张图（1440 宽，2 倍清晰度，浅色背景） |

## 重新生成

```bash
python docs/hex-contrast/make_html.py        # 数据 → 网页（换了 hexdata.json 才需要）
python -m pip install playwright             # 只装 Python 包，不用下载浏览器
python docs/hex-contrast/to_images.py        # 网页 → 图片（用本机 Edge；没有 Edge 改脚本里 channel="chrome"）
```

换了新数据后，模板里写死的结论（"收益中位数，全部海克斯第一""仅次于科学狂人""最好和最差差了 17 个百分点"、神组合的说明文字）要人工核对是否仍成立。

## 分页规则

- **一个 `<section>` 一张图**，从不在段落中间切开：统计卡、条形图和说明文字总在同一张里。页面里有几个 `<section>` 就出几张，文件名按 `to_images.py` 里的 `NAMES` 顺序取。
- 现在是 5 张：
  1. 标题 + "怎么读" + 科学狂人（最长，约 1440×2526）
  2. 逃跑计划
  3. 全能龙魂
  4. 虚幻武器（左右对比条：拿了亏为红、拿了赚为绿）
  5. 单英雄神组合 + 统计说明
- 每张单独转发也看得懂：
  - 顶部一行"海克斯大乱斗 · 国服 16.19"和页码（如 1 / 5）；
  - 第 1 张额外带大标题和"收益怎么读"；
  - 底部一行"收益"的定义和版本日期；最后一张用页面原来的页脚（含"属于相关性"的说明）。
- 宽 720 CSS 像素（手机阅读宽度），按 2 倍导出；强制浅色主题，微信里最清楚。
- 加新段落：在 `template.html` 里新增一个 `<section>`，再在 `NAMES` 里补一个文件名。

## 口径

收益 = 拿了这张海克斯的对局胜率 − 该英雄平均胜率（百分点）。英雄平均胜率用 Hexdata 自带的"胜率提升"反推（大样本海克斯的中位数，见 `lolhex/data/hexdata.py`）。每个英雄只统计 ≥3000 场的海克斯；名次是在该英雄所有 ≥3000 场海克斯里按收益排。统计属于相关性，跨一百多个英雄都稳定为正的牌、以及几十万场的单英雄组合最可信。
