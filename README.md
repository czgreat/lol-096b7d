# LOL 海克斯大乱斗助手

国服「海克斯大乱斗」的本地助手。**不接入 LCU、不读游戏内存、不注入、不模拟操作**，只截屏识别 + 显示数据。

## 组成

| 部分 | 作用 |
|---|---|
| 游戏助手 `lolhex` | Windows（无边框模式，默认 4K）。选英雄界面：截图识别英雄，显示胜率、评级、出装、加点；进游戏后：识别三张海克斯并推荐 |
| 数据服务 `lolhex.service`（可选） | 定时抓取公开数据源并缓存，提供网页看板和给游戏助手用的接口 |

## 数据来源

- **腾讯国服**（`mlol.qt.qq.com` / `game.gtimg.cn`，每天更新）：海克斯字典、英雄榜、海克斯层级与出场率、出装、加点、海克斯总体胜率；装备和召唤师技能的名字与官方图标。
- **ARAMGG**（`data.dtodo.cn`，需要自己的 API Key）：单英雄 × 海克斯胜率。
- **虎牙**（公开 CDN）：单英雄海克斯胜率快照，用来交叉核对和兜底。
- **Hexdata 快照**（可选）：数据目录里放 `hexdata.json` 时优先使用；仓库不附带。
- 评分以「平滑后相对英雄基准的Δ胜率」为主，选取率不参与打分。

## 安装与运行

**安装包**：运行 `LolHex-Setup-<版本>.exe`。
- 中文向导，默认装到 `%LOCALAPPDATA%\Programs\LolHex`，不需要管理员权限。
- 会创建开始菜单快捷方式，桌面快捷方式可选；自带卸载程序。

**打包**（开发机）：`pwsh -NoProfile -File packaging/build.ps1`
- 需要 `.venv` 和 Inno Setup（`winget install --id JRSoftware.InnoSetup -e --scope user`）。
- 产物在 `build/installer/`，约 100MB。

从源码运行：双击 `start.cmd`。第一次运行会创建虚拟环境并安装依赖。

- 游戏需要设为**无边框**或窗口化；独占全屏下浮窗看不到，截图可能是黑屏。
- 配置文件在 `%APPDATA%\lolhex\config.json`：
  - `nas_url`：自建数据服务地址（`python -m lolhex.service`），默认留空，直连公开数据源。
  - `use_liveclient`：是否读取游戏内 2999 接口，默认 `false`。
  - `show_winrate`：是否显示胜率数字。
- 选英雄界面（客户端在前台时，选人阶段每 0.5 秒、其他界面每 1 秒截图一次）：
  - 每个位置记住上次识别时的画面，没变就直接用上次结果，画面静止时一次扫描约 1–2ms；换英雄、刷新后只重新识别变了的位置。没认出来的结果不复用，下次照样重认（卡片、文字是淡入的，避免中途认一次后一直沿用「认不出」）。
  - 日志（`%APPDATA%\lolhex\lolhex.log`）记录看到「选择你的英雄」、认出英雄卡的时间，以及单次识别超过 0.8 秒的情况，用来查卡片标注慢在哪一步。
  - 启动时先用本地缓存加载头像库、预热文字识别，第一次进选人不用等。
  - 先读预选栏左边的"可用"两个字，确认当前是选英雄界面；大厅、房间等界面不识别，也不标注。客户端切到别的程序时标注隐藏；点右上角自己的浮窗不算切走，标注照常显示。
  - 开局"选择你的英雄"（二选一/三选一）：这时预选栏被盖住、没有"可用"，改读卡片上方的"选择你的英雄"来确认，卡一出现就标，不用等点完卡。按亮度切出每张卡下方的英雄称号再逐段识别，在卡片下面标评级和胜率，胜率最高的那张加金框并标"推荐"。
  - 顶部预选栏的头像，和官方方形头像库比对（客户端头像裁得更紧，头像库按几种放大倍数各算一份）。头像库在首次启动时从腾讯 CDN 下载到 `%APPDATA%\lolhex\data\icons`，约 3.6MB。
  - 左侧我方 5 人显示的是皮肤头像，所以改读每行的英雄称号文字；称号是金色字的那一行是自己。和待选栏或队友换英雄后，每 2 秒会重新识别，自动跟着更新。
  - 在每个头像旁悬浮显示评级和国服胜率。评级按国服胜率排名换算：前 10% 为 S，30% 为 A，60% 为 B，85% 为 C，其余为 D。腾讯英雄榜自带的排名掺了出场率，所以不用。
  - 预选栏里胜率比自己当前英雄高的标绿色，其中最高的加金框。浮窗和主界面还有一行"待选栏"汇总，按胜率排序。
  - 位置按 1920×1080 标定、存成窗口比例，1080p / 2K / 4K 通用。
- 游戏内海克斯三选一：
  - 只截三个标题所在的一条窄带，每 0.3 秒看一次；画面没变只比一次缩略图，变了才识别三个标题（4K 下约 30ms）。
  - 第一次用时先按国服 4K 实测的默认位置读（其他宽高比按"界面按高度缩放、水平居中"换算）；三张都对上就存成本机校准，写在 `%APPDATA%\lolhex\calibration.json`。默认位置对不上时照常整块扫描（约 0.6s，每 3 秒一次），扫到三张后自动校准。
  - 识别模型在启动时就预热，第一次出海克斯不用等模型加载（约 1.3s）。
  - 推荐框画在每张卡标题的正上方（压住图标下半部分），不挡海克斯名字、描述和下方的刷新按钮。
  - 前 3 次出现三选一时，趁浮窗还没画上去自动存一张截图（缩到 1920 宽）到 `%APPDATA%\lolhex\shots`，用来核对浮窗位置；存够 3 张就不再截。
- 英雄识别不出来时，在浮窗里点候选英雄，或输入名字手动选择。搜索支持别名：名字、称号、英文名、腾讯关键词里的拼音缩写（如 tm、kp），以及玩家常用叫法（如提百万、快乐风男；`lolhex/data/hero_aliases.json`，数据来源：Hexdata（hexdata.com.cn））。
- 出装与加点：装备只显示官方图标（不再带名字）。出装按胜率从高到低排，出场不到同类最热门 1/10 的不参与（样本太少，胜率说明不了什么）。图标首次显示时从腾讯 CDN 下载到 `%APPDATA%\lolhex\data\img`，下载好之前先显示文字。
- 用截图排查识别问题：`python -m lolhex --scan-image 截图.png --hero 提莫`

## 开发

```bash
python -m venv .venv && .venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m pytest -q tests          # 测试
python -m lolhex.service --port 25999 --data ./svcdata   # 本地起数据服务
```
